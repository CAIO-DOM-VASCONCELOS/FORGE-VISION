DIRECT GROQ · HUGGING FACE

Conexão da IA

O FORGE lê GROQ_API_KEY diretamente do Secret do Hugging Face. Sem a chave, o motor analítico local continua funcionando normalmente.

Secret: GROQ_API_KEY
Optional Variable: GROQ_MODEL
Default: openai/gpt-oss-20b
A chave não fica escrita no repositório. Neste modo Static direto, ela chega ao JavaScript do navegador para chamar a Groq; use uma chave dedicada e revogável.

Dados & CSV

Persistência híbrida

Pasta de trabalho local

Vincule uma pasta do computador. O FORGE mantém planilhas CSV atualizadas para estoque e movimentações, além de um backup JSON.

forge_inventory.csv
forge_movements.csv
forge_workspace.json

Persistência no navegador

Mesmo sem pasta vinculada, os dados permanecem salvos neste navegador e neste dispositivo. A pasta vinculada adiciona uma cópia física que pode ser aberta no Excel.

Importar movimentações

CSV: date,sku,type,qty,unitValue,note. Tipos: IN/OUT ou ENTRADA/SAIDA.

Backup manual

Use backup JSON para transportar todo o workspace para outro navegador ou computador.

Zona de perigo

RESET

Apague produtos, movimentações e os arquivos de estoque da pasta vinculada para começar uma operação do zero. Configurações como idioma, moeda e chave da IA não são apagadas.
